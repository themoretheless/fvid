# Exact owned LD-SBR Q31 reconstruction with explicit strict admission

The six original ISO inverse-filter streams previously fail at reconstructed
noise Q31. The new default LD-SBR policy admits exactly that additional value
and reconstructs2^(6-Q),including retaining31 in temporal coefficient history.
It neither substitutes PCM nor clamps31 to30. All26 original ISO LD-SBR inputs
now decode completely through the normal presented MP4 audio reader,versus20
before;all input SHA256s match the previous audit exactly.

## Policy and ownership

ISO/IEC14496-3:2009 section4.6.18.3.6 specifies reconstructed level noise0..30;
section4.6.19 does not specify a widened LD range. Q31 admission is explicitly
an interoperability extension,not a redefinition of that normative range or a
new AAC profile. The original pinned FDK also decodes all AUs of the six inputs
without concealment flags;its broader0..35 clamp is not adopted here.
The prior [source/FDK audit](aac-eld-sbr-noise-range-2026-10-31.md) retains the
original strict-default failures and source evidence.

`AacDecodeOptions::ld_sbr_noise` and the owned low-level decoder expose
`aac_eld_sbr::NoisePolicy::{Strict,AllowQ31}`. Default LD-SBR uses AllowQ31;
Strict keeps the normative refusal. The standalone strict `noise` and
`coupled_noise` helpers and ordinary/HE-AAC SBR retain their existing contracts.
Coupled balance bounds/evenness,checked temporal integer reconstruction and
finite DSP bounds remain enforced. Q32 is still an error in the default mode.
No external codec or FFmpeg enters production;all reconstruction stays in Rust.

The selected policy survives reset and is part of native checkpoint admission.
Restoring between Strict/AllowQ31 decoders fails before mutating history. Both
fvid-media and the root native frontend support explicit selection,with and
without the negotiated output clock. For strict validation:

```rust
use fvid_media::owned_aac::{AacDecodeOptions, NativeAacDecoder, aac_eld_sbr::NoisePolicy};
let decoder = NativeAacDecoder::new_with_options(asc, AacDecodeOptions {
    ld_sbr_noise: NoisePolicy::Strict,
    ..Default::default()
})?;
```

The Rust options struct gains one field;repo callers spelling every field now
use the default remainder where appropriate. The public low-level consuming
`with_noise_policy` builder selects future admission while retaining history.

## Authored acceptance and bounds

`aac-ld-sbr-q31` contains18 authored eight-AU programmes in MP4/Matroska:
480/512 cores,inverse filtering,centered coupling,asymmetric coupling and Q7,
Q30,Q31.36 movies match an independent direct CLDFB/HF/noise PCM oracle.
Q7 controls regenerate exactly the prior own packet/PCM bytes. Q31 is followed
by a temporal-24 back toQ7 and a temporal hold,so clamping31 to30 would corrupt
the subsequent waveform. A direct dequantization test checks exact2^-25 and
the centered/asymmetric coupled formulas separately.

Six more programmes (12 movies) reach31 then transmit a temporal+1 to32.
They fail at the exact Q32 bound;repeated failure retains Q31/core/filter history
for a correct retry. Strict Q31 refusal,reset,checkpoint replay and cross-policy
restore are also exercised. The older Q31 refusal movies become executable
default acceptance without any movie/AU/PCM asset changes;their metadata/tests
now explicitly distinguish the Strict-policy refusal.

The actual audio worker checks all36 new accepted movies:initial PCM,live-history
forward/backwards/repeated seeks,either side of core boundaries,EOF,rewind and
presentation timestamps. Ordinary tests run from frozen fixtures and require
no generators,foreign codecs,FFmpeg or network access. Two generation runs with
sockets and subprocesses disabled reproduce every file byte-for-byte. No
private/ISO video,frames,audio or codec parameter sets enter the own corpus.
