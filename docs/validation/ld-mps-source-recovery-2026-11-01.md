# Additional public source previews for the remaining LD-MPS work

Old PDF-shaped URLs now redirect to HTML product pages. Following their public
viewer links recovered three actual PDF previews; their exact URLs, cache paths,
byte lengths, page counts and SHA256 identities are in the adjacent JSON. PDFs
remain in the external reference cache and are not copied into the repository.
No purchase, account access or license acceptance was performed.

The generic MPEG Surround preview contains57 PDF pages, through printed page51:
https://robstandard.com/wp-content/preview/02596f6e4fd2405c6176050315b0eb11.pdf
Its Table8 and Table53 distinguish the number of HRTF level bands from the
number of phase entries. The retrieved field definition does not itself give
a different-grid conversion algorithm or justify requiring equal resolutions.
It is not the complete standard, so absence of a condition in this preview is
not proof that no such condition exists elsewhere.

This is relevant to the phase-lift counterexamples recorded in
`aac-ld-mps-hrtf-partitions-2026-11-01.md`, but it does not resolve their normative
meaning for LD-MPS. The pinned original low-delay source reads a phase entry
for each of its HRTF bands and sets ICC absent; the generic syntax differs.
Transplanting generic phase-count rules would therefore be an unqualified
change to the LD parser. The LD-specific AnnexB must establish its grammar,
phase-band interpretation and processing rules before production admission
changes or waveform acceptance can be claimed.

The newly recovered2010 SAOC preview has27 PDF pages and ends on printed21;
AnnexB is absent. The Cor2:2014 preview contains only its cover. Neither supplies
the missing low-delay rules. Index-first local RAG retrieval also supplied no
relevant normative source; that result is not an exhaustive storage audit.

No production code or acceptance expectation changes accompany this research.
Unequal HRTF grids, other unqualified EBQ configurations and inherited prefix
loss remain open. This source recovery does not complete the codec-gap goal.
