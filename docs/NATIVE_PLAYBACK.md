# Собственное воспроизведение FVid

Целевая зависимость: приложение → библиотека FVid → собственные контейнеры,
декодеры и обработка кадров. FFmpeg разрешён только в бенчмарках.
Оконная библиотека и графический API не выполняют декодирование медиа.

## Реализовано

- `fvid::playback::Y4mReader`: последовательное чтение локального Y4M,
  ограничение буферов до выделения памяти, проверка размера и маркеров,
  положительная рациональная частота кадров, повторное чтение с начала.
- Собственное преобразование 8-bit YUV420jpeg / YUV422 / YUV444 в RGB,
  BT.601 limited range, ближайший chroma sample. Цветовая матрица и
  sample aspect ratio не определяются автоматически.
- `fvid::player`: Open, drag-and-drop, пауза, Restart, сохранение окна после EOF.
  Без входного файла открывается пустое окно. Звука, seek и playlist пока нет.
- `cargo build --no-default-features --features player` не включает `fvid-media`.
  Лимит 64 MiB относится только к переиспользуемым YUV/RGB-буферам reader;
  графические ресурсы, UI-копии и драйвер в него не входят.

Y4M хранит несжатые кадры: это собственный контейнерный reader и raw-video
путь, а не реализация H.264 или другого сжатого кодека. Неподдерживаемые
файлы отклоняются без fallback на FFmpeg.

Собственный MP4-demux и bitstream primitives уже добавлены отдельно от
плеера: [прогресс контейнеров и кодеков](CODEC_PROGRESS.md). Они пока не
декодируют сжатые кадры.

## Что ещё требуется

1. Выбрать первый контейнер и профиль сжатого кодека; зафиксировать
   поддерживаемый поднабор, ограничения и независимый тестовый корпус.
2. Реализовать собственные demux, packet/timebase API и декодер в FVid;
   проверять повреждённые потоки, лимиты памяти, порядок кадров и seek.
3. Добавить собственный аудиодекодер, синхронизацию и звук.
4. Перенести потребителей `fvid-media` (редактирование, экспорт, MCP),
   затем удалить libav из production-зависимостей полностью.

Legacy `media` пока остаётся в репозитории для сохранения существующих
функций; он противоречит конечной цели и не считается собственной
реализацией контейнеров или кодеков.
