## Format scope

[Microsoft's AVI RIFF reference](https://learn.microsoft.com/en-us/windows/win32/directshow/avi-riff-file-reference) assigns WAVEFORMATEX data to the audio strf chunk. The [WAVEFORMATEXTENSIBLE reference](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ksmedia/ns-ksmedia-waveformatextensible) defines the extended subformat,precision and speaker fields. The adapter now shares its already validated RIFF/WAVE parser for uncompressed integer/float subformats rather than introducing a more permissive AVI interpretation.

Only PCM/IEEE float extensible subformats are added. Classic AVI PCM,G711 and ADPCM retain their existing paths. Unknown or unsupported GUIDs remain Unsupported and are skipped during playable-track selection; malformed recognized extended headers return Invalid. One fixture places an unknown GUID stream before a valid extensible stream and verifies complete playback of the latter. Valid-bit precision stays left-aligned in its stored byte width. Existing device routing supplies speaker weights; no new matrix policy or decoder algorithm is introduced. The validator visibility changes only to pub(crate),with no external signature migration.
