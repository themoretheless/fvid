# MP4 tx3g Unicode decoding

The primary format reference is ETSI TS126245 V10.0.0, sections5.1,5.16 and5.17:
https://www.etsi.org/deliver/etsi_ts/126200_126299/126245/10.00.00_60/ts_126245v100000p.pdf

BOM-marked UTF-16 big-endian text is required; byte-reversed support is optional. Lengths count bytes. The witnesses declare a full visible default style and its font table, with no copied private media or codec parameters. The earlier signed-clock witnesses were also upgraded to complete font descriptors. Original73ec5a still reproduces their exact timing defect:1pass2fail; no extra improvement is counted for this qualification repair.

Thirteen acceptance videos cover UTF-8 controls, required big-endian UTF-16, optional little-endian, surrogate-pair scalars, markup/newlines, styled text and supported legacy grouped/boxed forms. Empty BOM-only text is hidden. Fifteen separate malformed-cue refusals cover odd byte counts and unpaired high/low surrogates across five forms; healthy following text and all video pictures remain intact. The test explicitly distinguishes valid text acceptance from malformed-cue rejection/recovery. Each file contains three real authored colored VP9 frames, verified against independent planes, plus exact packet snapshots. The generator is offline and separate from ordinary tests.

Public interfaces and timestamp policy remain unchanged. Exact video seek, cue contents and bounds are exercised. Renamed initial fixtures were byte-identical to final names; the mapping is retained, with no sample bytes lost.
