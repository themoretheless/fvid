# Compact MP4 sample-size tables

Accepted as FVID-0432. Original production requires stsz in sample_index and does not discover ISO compact stz2. Initial authored witnesses cover16-bit VP9 sizes and4/8/16-bit tx3g sizes, paired with packet-identical stsz controls. Both odd/even nibble counts, high-bit byte sizes and multi-byte word sizes are included. All ten movies retain the three authored16x16 video pictures and60ms video clock; the four-caption case has its own100Hz40ms text clock.

The optional independent-packet-index.json cross-check validates each video/text packet size, PTS and SHA256 using ffprobe. This tool is separate from generation and ordinary tests, which use no encoder or network. All media, caption strings and parameters are authored rather than copied from private source.

Primary comparison implementation:
https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavformat/mov.c#L3194-L3279
Format reference:ISO/IEC14496-12:2015 section8.7.3.3. No source code is copied.

Acceptance requirements (now verified): establish original control/acceptance results, implement standard4/8/16-bit sizes with checked body extents, preserve regular stsz behavior and actual packet order, verify explicit malformed/ambiguous-table refusals and limits, preserve uniform PCM indexing when the compact entries state one constant size, and run related parser/playback/seek/EOF/subsystem tests and builds. All field/audio/fragment variants are one ID; no performance claim.

Final candidate coverage now comprises20 valid movies (16 classic pairs including PCM/MACE and4 real fragmented init/edit controls),13 explicit malformed/ambiguous table witnesses and25 oracle/manifest files:58 total. Every malformed witness retains authored video. All six final focused regressions pass before the final original-source repeat; the restored original9e581b1573 passes1 regular-size control and fails5 acceptance/integrity tests on that same final corpus, then candidate bytes are restored in finally and checked against a task-owned staging backup.

The implementation borrows validated size-table payloads, checks exact byte counts before index allocation and decodes high/low nibbles, bytes or big-endian words. It rejects both tables together, missing tables, unsupported widths/version, reserved bits, mismatched payload/counts and zero sizes. Per-width byte arithmetic avoids unnecessary bit-count overflow on32-bit usize. Compact constant-size PCM retains the existing uniform/chunk index, verified at a total4-record budget with2880 actual PCM frames; all PCM suffixes after media seeks match an authored f32 oracle. MACE keeps six-sample block units and the same exact PCM as its ordinary counterpart. A prototype zero-MACE-size bypass is separately reproduced (4pass1fail) and corrected before acceptance; this introduced guard gap adds no ID. A test initially expected the wrong error category for unsupported box version; existing Invalid classification is retained and the stage log preserved.

Real fragmented controls replace only the empty text init sample-size table in the earlier authored FVID-0429 open-edit witness. Their text moof/trun packets, edited captions and actual native seeks/40ms video intervals remain exact. Independent optional ffprobe records cover all20 valid video mappings, text packet hashes and audio geometry/duration. Initial29 media/oracle files remain byte-identical; the original initial manifest is reconstructed exactly by removing later additions and matches its initially captured SHA256. No external source implementation or private codec parameters are copied. No speed/process-wide RSS/physical-device claim is made. Broader qualification is green.
