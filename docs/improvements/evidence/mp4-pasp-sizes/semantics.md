Apple documents the pasp payload as exactly hSpacing and vSpacing, each an unsigned 32-bit integer: https://developer.apple.com/documentation/quicktime-file-format/pixel_aspect_ratio . The current parser discards read errors via .ok(), treating a truncated present box like absence, and ignores extra bytes. Only the fixed payload size is tightened here. The existing zero-spacing fallback policy and absence remain unchanged and are explicit positive controls. This is malformed-box refusal, not a visual-renderer or aspect-correction improvement.
