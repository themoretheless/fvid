ISO/IEC 14496-12:2015 sections 8.8.7.1 and 8.8.8.1 define tfhd duration-is-empty (0x010000): the default duration names an interval with no samples, and no trun boxes are permitted. Reference document: https://hezhaojiang.github.io/slave/MP4/ISO-IEC-14496-12-Base-Format-2015.pdf . The cursor must advance through an empty interval even when the following populated fragment omits tfdt. The gap adds no packet and consumes no per-sample index budget. Playback preserves the existing hold-until-next-picture interval behavior for a gap between pictures; a trailing gap extends declared duration without inventing or retiming a final picture.

The first audit hypothesis concerning implicit byte bases was not changed: existing per-run chaining matches the sequential addressing model. No separate improvement is counted for that audit.
